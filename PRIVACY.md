# Privacy and public contributions

Converter processes local media through its bundled engines. Downloading media,
checking for releases, and obtaining model files contact the corresponding remote
services. Those services receive network requests and apply their own policies.

Bug reports are saved locally or copied to the clipboard. They are not submitted
automatically. Review reports before sharing: descriptions and logs can contain
file paths, source URLs, or other information you entered. Contact email is optional.

Keep signing keys, passwords, access tokens, environment files, generated build
files, and personal logs outside Git. Use generic usernames and paths in examples.
The Linux release workflow stores private signing credentials in a restricted
GitHub environment; only the public verification key is committed.

This project uses neutral application branding and contributor attribution.
The GitHub repository owner remains visible in its public URL and the updater
endpoints required to download releases. Earlier commits retain their original
content and attribution; the current cleanup does not rewrite Git history.

The project source is available under the MIT license. Dependencies, models, and
bundled third-party tools retain their own licenses.
